# Backend roadmap after milestone 1

1. **Identity and tenancy:** models, admin-provisioned accounts, secure sessions, role/resource authorization, and audit events.
2. **Inventory and connectivity:** device/camera/assignment records, encrypted credential references, capability schemas, vendor interfaces, and ONVIF discovery.
3. **Gateway and media:** edge enrollment, secure outbound connectivity, authenticated local/remote media sessions, feature gating, and optional FFmpeg deployment.
4. **Security operations:** alert and notification pipelines, offline/after-hours rules, AI-worker contracts, observability, retention, backups, and deployment hardening.

These milestones are planned, not implemented.
