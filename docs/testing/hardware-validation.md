# Hardware validation

Pending tests require authorized Dahua, CP Plus and Hikvision devices. Validate ONVIF/vendor event support separately per firmware; unsupported devices must use a gateway adapter or report unsupported. Verify motion/tamper/storage events, replay behavior, disconnect hysteresis, recovery, snapshots and streams without committing credentials.

AI and Expo tests require actual licensed models, runtime dependencies, representative footage, an Expo project, a mobile build and a physical device. Mocked fixtures are not real-world validation.
